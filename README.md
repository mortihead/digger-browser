# Digger — браузерный порт

Порт классической игры [Digger](https://ru.wikipedia.org/wiki/Digger) на TypeScript.
Работает в браузере на `<canvas>` + Web Audio, без внешних ассетов (вся графика
и звук зашиты в код / синтезируются).

Поиграть можно тут:
[mortihead.github.io/digger-browser](https://mortihead.github.io/digger-browser/)

Основан на Java-версии игры: [github.com/mortihead/digger](https://github.com/mortihead/digger).

## Как запускать (для разработки)

Нужен установленный Node.js (проверено на версии 20).

Аналогия с Java/Maven:

- `npm` ≈ Maven, `package.json` ≈ `pom.xml`;
- `node_modules/` ≈ локальный репозиторий зависимостей (`~/.m2`);
- Vite ≈ сборщик + встроенный dev-сервер (как Tomcat в дев-режиме).

Команды (выполнять из каталога проекта):

```bash
# Один раз: установить зависимости (аналог mvn install)
npm install

# Запустить dev-сервер с горячей перезагрузкой
npm run dev
```

После `npm run dev` в консоли появится адрес, обычно http://localhost:5173 —
открыть его в браузере. При изменении файлов страница обновляется сама,
пересобирать вручную не нужно.

Остановить сервер: `Ctrl+C` в терминале.

## Как проверять

- Открыть http://localhost:5173 в браузере (вкладка должна быть активна —
  при потере фокуса игра ставится на паузу).
- Ошибки TypeScript/сборки видны прямо на странице (красный оверлей) и в терминале.
- Ошибки времени выполнения — в консоли браузера (DevTools, F12 → вкладка Console).
- Звук включается после первого клика или нажатия клавиши (требование браузеров
  к автозапуску аудио).

## Сборка релиза

```bash
npm run build      # проверка типов (tsc) + сборка в каталог dist/
npm run preview    # локально посмотреть собранный релиз
```

Каталог `dist/` — статические файлы, их можно выложить на любой хостинг.

## Деплой на GitHub Pages

В репозитории настроен workflow [.github/workflows/deploy.yml](.github/workflows/deploy.yml):
при пуше в ветку `main` игра автоматически собирается и публикуется на GitHub Pages.

Чтобы это заработало, в настройках репозитория (Settings → Pages) нужно один раз
выбрать источник **GitHub Actions**.

## Управление

- Стрелки — движение
- F1 — огонь (выстрел)
- Space — пауза / продолжить
- Enter — старт игры (на титульном экране)
- Esc — переключение 1/2 игрока (на титульном экране)
- F7 — вкл/выкл музыку
- F9 — вкл/выкл звук
- F10 — вернуться на титульный экран
- `+` / `-` — скорость игры

## Об архитектуре порта

Оригинал написан на Java с использованием AWT (графика) и Java Sound (звук).
Порт сохраняет структуру классов оригинала, заменяя платформенные части
браузерными аналогами:

- CGA-дисплей 320×200 → буфер пикселей → `<canvas>` (масштабирование средствами
  браузера без сглаживания);
- спрайты и шрифт (зашиты в код как массивы) → сгенерированы скриптом
  `scripts/convert-graphics.mjs` из Java-исходников;
- синтез PC Speaker → `OscillatorNode` + `GainNode` (Web Audio API);
- игровой цикл на потоках и `Thread.sleep` → `async/await` поверх `setTimeout`;
- ввод с клавиатуры AWT → браузерные события `keydown`/`keyup`;
- сохранение рекордов (`java.util.prefs`) → `localStorage`.
